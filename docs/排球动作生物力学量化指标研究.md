# 排球动作评分指标：生物力学量化研究

> 目的：为面向高校教练与学生的动作评分系统，建立"有文献依据、可测量、可复现"的量化指标体系
> 方法：检索 Crossref / PubMed 权威期刊文献，提取可引用的量化结论，并转化为可实现的算法指标
> 版本：2026-09-21

---

## 一、总体思路：三层结构

**第一层：原始运动学**（可测量的物理量）
关节角度、角速度、身体重心速度、球速、时间/时序、关节力矩与功（需测力台或逆动力学）。

**第二层：特征指标**（对教学有意义、可解释）
例如"击球瞬间肩外展角""起跳阶段髋/膝角速度""落地缓冲期膝屈曲角""前臂平台稳定性"。

**第三层：判定与反馈**（教学语言）
例如"击球点偏后""起跳蹬伸不足""落地缓冲不够，膝关节负荷偏高"。

**核心原则**：
1. 只把文献中有信度/效度支持的指标纳入评分；
2. 2D 姿态能算的指标与必须 3D/测力台的指标严格区分；
3. 所有指标都要报告测量误差（ICC/SEM/MDC），并与教练评分做一致性验证。

## 三、核心指标库（可直接实现）

> 每个指标给出：定义、公式（关键点）、文献依据、教学含义、实现难度。
> 公式中 A/B/C 表示关键点坐标，`∠ABC` 为以 B 为顶点的夹角（余弦定理）。

### A. 上肢（发球 / 扣球 / 传球）

| 指标 | 定义与公式 | 文献依据与数值 | 教学含义 | 难度 |
| ---- | ---- | ---- | ---- | ---- |
| 击球瞬间肩外展角 | ∠(躯干-肩-肘) 的额状面分量 | Reeser 等（2010，Sports Health）：击球瞬间肩外展 ≈130°，显著大于网球发球与棒球投球 | 肩外展过大是排球特有的高负荷姿态，与肩部过用损伤相关 | 中（需额状面视角，OpenPose 肩关节效度差，建议后视机位） |
| 肩水平内收角 | 上臂在水平面相对躯干的角度 | Reeser 等（2013，Br J Sports Med）：排球扣/发在击球瞬间肩外展与水平内收大于其他过顶运动 | 反映挥臂"从后到前"的转体与鞭打 | 高（2D 难，需双视角/3D） |
| 肘关节屈曲角 | ∠(肩-肘-腕) | Reeser 等（2010）：肘部力矩与角速度在扣球时最大 | 挥臂鞭打的核心 | 低（2D 侧视可靠） |
| 肘/肩角速度 | 角度对时间一阶差分 | Sarvestan 等（2020）：成功扣球腕速高 ≈5.5%，挥臂速度高 ≈8.2% | 鞭打速度决定击球质量 | 低 |
| 肩旋转角速度 | 肩内外旋角速度 | "Shoulder 3D range of motion and humerus rotation in two volleyball spike techniques"（Sports Biomech 2015）；J Biomech 1989 | 与肩损伤风险相关 | 高（需 3D） |

### B. 躯干与下肢（发球 / 扣球 / 拦网）

| 指标 | 定义 | 文献依据与数值 | 教学含义 | 难度 |
| ---- | ---- | ---- | ---- | ---- |
| 骨盆前倾角速度峰值 | 骨盆前倾角一阶差分峰值 | Liu 等（2025，BMC Sports Sci Med Rehabil）：与跳发击球瞬间手速显著相关 | 躯干"鞭打"是力量传导关键 | 中（侧视 2D 可近似） |
| 髋关节角速度峰值 | 髋屈伸角速度峰值 | Sarvestan 等（2020）：成功扣球髋角速度高 **≈13.3%** | 踏跳蹬伸能力 | 低 |
| 膝关节角速度峰值 | 膝屈伸角速度峰值 | Sarvestan 等（2020）：成功扣球膝角速度高 **≈12.4%** | 起跳速度 | 低 |
| 起跳重心垂直速度 | 髋中心点垂直速度 | Sarvestan 等（2020）：成功扣球高 **≈6.5%**，跳起高度高 ≈4.3% | 起跳效率 | 中（需标定，像素→米） |
| 击球高度 | 手腕最高点相对身高 | Sarvestan 等（2020）：成功扣球高 ≈1.5% | 击球点高低 | 中（需标定） |
| 落地缓冲膝屈曲角 | 触地至重心最低点膝关节最小角 | De Bleecker 等（2024）：矢状面膝角 ICC **0.61–0.89**（信度可用） | 缓冲不足会增加膝关节负荷 | 低（侧视 2D） |
| 落地膝外翻角 | 额状面膝-踝连线相对髋-膝连线 | Ino 等（2024，J Sports Sci Med）：OpenPose 测 DVJ 膝外翻的效度/信度研究；Li 等（2026，Sports Health）LESS 评分 ICC 0.90–0.95（评分者内）、0.84–0.95（评分者间） | 膝外翻与 ACL 风险相关 | 中（需正面/后视机位，2D 可测但误差需报告） |
| 下肢关节功/力矩 | 关节功率积分 | De Bleecker 等（2025，J Sports Sci）：膝关节向心功越高，髌腱病风险越高（拦网 HR=1.323、扣球 HR=1.200、落地跳 HR=1.240）；离心功（拦网）HR=1.246 | 负荷管理的关键指标 | 高（需测力台 + 逆动力学，2D 不能直接测） |

| 指标 | 定义 | 文献依据与数值 | 教学含义 | 难度 |
| ---- | ---- | ---- | ---- | ---- |
| 传球时腿部参与度 | 蹬伸阶段髋/膝角速度或角位移 | Ozawa 等（2021，Sports Biomech）：长距离传球需要更多腿部动作；Ozawa 等（2022）：3/6/9 m 的腿动作显著不同 | "用腿传球"的教学要点 | 低 |
| 传球接触高度 | 手腕相对额/头顶的高度 | Ozawa 等（2021）：上手传球在额前上方接触 | 手型与接触点 | 低 |
| 前臂平台角与稳定性 | 两肘-两腕连线的角度与抖动 | Forearm Pass 研究（ICSSH 2020）；Paulo 等（2018）接发球动作选择 | 垫球平台指向与稳定 | 低 |
| 接球区域/站位 | 接球人与来球落点的相对位置 | Paulo 等（2018，J Sports Sci）：Voronoi 接球区识别接球人准确率 **95.05%**；来球速度/高度、与目标距离影响上手/下手选择 | 站位与移动效率 | 中（需场地标定） |
| 接发球质量代理指标 | 出球方向偏差、平台角度偏差 | Paulo 等（2018）：下手侧传与较低接球质量相关 | 一传质量 | 中 |

### D. 测量质量指标（所有动作通用）

| 指标 | 说明 | 文献依据 |
| ---- | ---- | ---- |
| 关键点检出率 | 有效帧占比 | 姿态估计效度研究（Baldinger 2025；Ino 2024） |
| 关节角信度 | ICC(3,1)/(2,k) | De Bleecker 等（2024）：矢状面 ICC 0.61–0.89；额状面髋膝 0.61–0.78；踝额状面与旋转面较差（0.28–0.53） |
| 测量误差 | SEM / MDC | 同上 |
| 与教练评分一致性 | Pearson / Spearman / Bland-Altman | 本项目计划实验设计（见第五节） |
| 相机角度敏感性 | 不同机位的角度偏差 | Baldinger 等（2025）：肩关节相关性差；不同视角存在显著偏差；**后视机位表现最好** |

## 四、测量学要求（决定指标是否"科学"）

1. **机位**
   - 后视（拍摄者位于运动员正后方）在 OpenPose 效度研究中表现最好（Baldinger 等，2025）；
   - 建议双机位：正后方（额状面：膝外翻、肩外展）+ 侧方（矢状面：髋膝肘角度、重心速度）；
   - 不做双侧同时采集时，明确标注"单视角近似"。
2. **2D 姿态的效度边界**
   - 膝、髋、肘关节角度与金标准相关性可接受；
   - **肩关节相关性差**（Baldinger 等，2025）——肩部指标必须双视角或 3D，否则不应纳入正式评分；
   - OpenPose 测膝外翻有专门效度研究（Ino 等，2024），需报告 MAE/CMC。
3. **运动学信度**
   - 优先使用矢状面指标（ICC 0.61–0.89）；
   - 避免踝额状面/旋转类指标（ICC 0.28–0.53）；
   - 落地阶段**只取中段稳定窗口**（起止段信度较差，De Bleecker 等，2024）。
4. **标定与归一化**
   - 用场地单应把像素换算为米；
   - 角度用关节角度本身（不受尺度影响），高度/距离用身高等归一化；
   - 2D 姿态到地面反作用力的估计已有方法研究（Sensors 2022），但误差较大，不能替代测力台。
5. **报告规范**
   - 每项指标报告：样本量、机位、采样率、滤波（建议 Butterworth 低通 6–10 Hz）、ICC、SEM、MDC。

## 五、与教练评分一致性的实验设计（本项目要做的核心验证）

**目的**：证明"系统的量化指标"与"教练的教学判断"一致。

**步骤**：
1. 拍 20–30 段视频：垫球、发球、传球各 8–10 段，室内外各一半；
2. 教练对每段给出：总体评分（1–10）与分项评分（准备、击球、跟随）；
3. 系统输出：分项指标值（角度、角速度、时序）与综合分；
4. 统计：
   - Pearson / Spearman：系统综合分 vs 教练总体分；
   - ICC(2,k)：分项指标 vs 教练分项评分；
   - Bland-Altman：系统与教练差异的偏差与一致性界限；
   - 分项回归：找出对教练评分贡献最大的指标（用于调整权重）。
5. 判定标准（建议）：
   - 综合分 Spearman ≥ 0.7 视为"较好一致"；
   - 分项指标 ICC ≥ 0.75 视为"可接受"；
   - 对不达标指标，先检查机位与信度，再决定是否保留。

**文献支撑**：De Bleecker 等（2024）给出了排球跳落地任务的信度基准；Li 等（2026）给出了落地评分工具（LESS）的信度与预测效度区间，可作为方法学参考。

## 六、从指标到教学反馈（有实验支持）

- Parsons & Alexander（2012，J Strength Cond Res）：对 12–14 岁女子排球运动员给予**视频 + 语言反馈**，4 周后干预组的髋/躯干屈曲、踝背屈显著改善（p ≤ 0.05），说明"可视化 + 语言提示"能改变落地下肢力学；
- Black & Wiliam（1998，形成性评价）与 Hattie & Timperley（2007，反馈的力量）：及时、具体、可执行的反馈最有效；
- Salmoni 等（1984，Psychological Bulletin）：反馈频率过高会导致依赖，建议对高频繁反馈做"自适应降频"；
- 因此系统反馈应遵循：**具体指标 + 方向 + 幅度 + 一次只改一个点**（例如"落地时膝屈曲不足，先练落地缓冲"）。

## 七、落地实现方案（对应代码）

| 层 | 模块 | 要做的事 |
| ---- | ---- | ---- |
| 关键点 | `body.py` | 12 核心关节（已实现）；肩部指标需扩展视角/双机位 |
| 时序与事件 | `analyzer.py` | 已有的动作区间状态机；新增"起跳/击球/落地"事件检测 |
| 几何校正 | `geometry.py` | 场地单应尺度补偿（已实现）；新增双视角融合 |
| 指标计算 | 新增 `metrics.py` | 关节角度/角速度、重心速度、时序指标、归一化与信度标注 |
| 评分与反馈 | `pose_judge.py` | 权重改为"文献先验 + 数据校准"；反馈分级 |
| 验证 | 新增 `tools/validate_metrics.py` | ICC/SEM/MDC、与教练评分一致性、Bland-Altman 报告 |

**实施顺序（建议）**：
1. 先做矢状面指标（髋/膝/肘角度与角速度）——信度最高、2D 最可靠；
2. 再做额状面指标（膝外翻、肩外展）——需固定后视机位并报告误差；
3. 最后做时序与负荷代理指标（重心速度、落地缓冲），并明确标注"非测力台真值"；
4. 任何新指标都必须先通过"信度 + 教练一致性"两道门槛，才进入正式评分。

## 八、局限与学术声明

1. 上述数值来自论文摘要与元数据，正式引用前应核对原文的完整数值与统计口径；
2. 2D 姿态估计**不能替代** 3D 运动捕捉与测力台；关节功/力矩类指标需测力台 + 逆动力学；
3. 肩关节在单视角 2D 中效度差（Baldinger 等，2025），不建议单独作为评分依据；
4. 多数排球生物力学研究样本量较小（n≈12–27）、机位与任务不完全一致，**不能直接当作全国统一标准**；
5. 最好的做法是：用文献指标作为"先验"，再用本校数据做信度与一致性验证，形成校本标准；
6. 本系统的评分只用于教学辅助，不用于医学诊断。

## 十、本系统的实现（2026-09-21 初版）

### 1. 代码结构

| 文件 | 作用 |
| ---- | ---- |
| `metrics.py` | 逐帧生物力学指标（关节角度、平台角度、重心/腕部位置）与动作级汇总（相位检测、峰值角速度、起跳速度、跳跃高度、落地缓冲） |
| `analyzer.py` | 每帧采集指标，提供 `biomechanics_summary(fps)` |
| `analysis_service.py` | 视频/实时分析结果中输出 `summary.biomechanics` |
| `tools/validate_metrics.py` | 与教练评分的一致性验证（Pearson / Spearman / ICC(2,1) / Bland-Altman） |
| `index.html` | 结果页展示峰值膝角速度、髋角速度、起跳重心速度、起跳高度、落地缓冲膝角、平台稳定性 |

### 2. 关键实现决策（都有文献依据）

1. **只对矢状面指标做正式评分**：矢状面信度最高（ICC 0.61–0.89，De Bleecker 2024）；
2. **肩关节不做单视角评分**：OpenPose 在肩关节效度差（Baldinger 2025），仅记录参考值；
3. **位置统一归一化**：用整段序列的**中位身高**做基准（避免下蹲时"逐帧身高"变小导致数值虚高）；
4. **信号滤波**：角度约 6 Hz 低通、位置约 4 Hz 低通（滑动平均近似），并对位置序列做中位数±3×MAD 极值裁剪；
5. **相位检测**：以髋部高度序列的最高点为基准，检测起跳（向上速度 > 0.5 身高/秒）与落地（向下速度 < -0.5 身高/秒）；仅当两个相位都检出时才输出落地缓冲指标；
6. **JSON 安全**：所有 NaN/Inf 输出为 `null`，避免前端解析失败。
