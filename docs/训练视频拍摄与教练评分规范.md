# 训练视频拍摄与教练评分规范

> 目的：让"系统评分 vs 教练评分"的一致性实验在方法学上站得住
> 适用：垫球（dig）、发球（serve）、传球（set）、扣球（spike）
> 版本：2026-09-21

---

## 一、视频拍摄要求

### 1. 机位（最重要）

| 动作 | 主视角 | 辅助视角 | 说明 |
| ---- | ---- | ---- | ---- |
| 垫球 / 接发球 | **侧面**（矢状面） | 后视 | 侧面看屈膝、前倾、平台角度；后视看膝外翻 |
| 发球 | **侧面** | 后视 | 侧面看抛球、挥臂、起跳；后视看肩外展 |
| 传球 | **侧面** | 后视 | 侧面看蹬伸与手型 |
| 扣球 / 拦网 | **侧面** | 后视 | 侧面看助跑、起跳、挥臂；后视看落地膝外翻 |

- 三脚架固定，**不要手持**；
- 镜头大致与髋部同高（约 1.0–1.3 m）；
- 摄像机距离 4–6 m，保证人物全身入镜，人物高度占画面 ≥60%；
- 若做双视角：两台设备**同时开始录制**，并在开头拍手/闪光一次作为同步标记，两台都要拍到全身。

### 2. 分辨率和帧率

- 分辨率：1080p 及以上；
- 帧率：30 fps 起，**60 fps 更好**（角速度类指标更准确）；
- 不要开数码变焦、防抖裁切等会改变画面几何的功能。

### 3. 每段视频的内容

- 时长：**5–15 秒**，包含 1–3 次完整动作；
- 或 30–60 秒，包含 5–10 次完整动作；
- 必须包含完整过程：准备 → 动作 → 击球/接触 → 落地/恢复；
- **不要剪辑、不要慢放、不要加滤镜**；保留原始文件；
- 同一个学生同一个动作至少拍 3 次。

### 4. 环境

- 光照均匀，避免逆光、强烈阴影；室内把灯全开；
- 背景尽量简洁，避免其他人在镜头前穿过；
- 学生穿贴身衣物、关节可见，避免宽大外套遮挡关节。

### 5. 标定（很重要）

- 用同一个机位，拍一张场地四角可见的画面（或一段 2 秒视频）；
- 在系统的"视角标定"页选择对应视角（视角 A / 视角 B）标好四角并保存；
- 分析时选择对应标定，系统才能做透视尺度补偿。

### 6. 文件命名与数量

- 命名：`动作_学生编号_视角_序号.mp4`，例如 `dig_S01_side_01.mp4`；
- 双视角成对命名：`dig_S01_side_01.mp4` + `dig_S01_back_01.mp4`；
- **统计最低要求**：每个动作 ≥20 段（30 段以上更好）；如果只做垫球，至少 20–30 段垫球。

## 二、教练评分怎么做

### 1. 两种评分方式（推荐第二种）

**方式 A：最简版（够用于相关性分析）**
- 每段视频给一个总分：1–10 分；
- 再标一个"标准 / 不标准"。

**方式 B：分项版（推荐，能分析到具体技术环节）**
- 总分（1–10）；
- 三个过程分（各 1–5 分）：准备姿势、击球/接触、跟随/落地缓冲；
- 四个生物力学分项（各 1–5 分）：膝屈曲、躯干前倾、手臂伸展、落地缓冲；
- 可以只填总分，其他留空，工具会跳过空值。

### 2. 评分锚点（1–10 分，供教练统一尺度）

| 分数 | 含义 |
| ---- | ---- |
| 9–10 | 非常标准，可直接作为示范 |
| 7–8 | 基本标准，有小的可改进点 |
| 5–6 | 一般，有明显偏差 |
| 3–4 | 偏差较大，需要重点纠正 |
| 1–2 | 动作明显错误或无法完成 |

分项 1–5 分的含义：5 = 标准；4 = 基本标准；3 = 有明显偏差；2 = 偏差较大；1 = 严重错误。

### 3. 评分纪律（保证统计有效）

- 建议 **2 名教练独立评分**：互不看对方分数，也不看系统分数；
- 评分顺序随机，不要按"好/坏"分组评；
- 样本里要**同时包含标准与不标准的动作**，否则相关性会失真；
- 同一名学生同一动作至少 3 段，避免只看一次发挥。

## 三、评分表格式（CSV）

模板文件：`tools/coach_rating_template.csv`

| 列 | 必填 | 说明 |
| ---- | ---- | ---- |
| video | ✅ | 视频文件名（与 --videos 目录中的文件同名） |
| student | 建议 | 学生编号 |
| action | ✅ | dig / serve / set / spike |
| cam_view | 建议 | side / back |
| coach_id | ✅ | 教练编号（如 coachA / coachB） |
| reps | 可选 | 该视频里完整动作次数 |
| overall_score | ✅ | 总分 1–10 |
| standard_flag | 可选 | 1=标准，0=不标准 |
| prep_score | 可选 | 准备姿势 1–5 |
| contact_score | 可选 | 击球/接触 1–5 |
| follow_score | 可选 | 跟随/落地缓冲 1–5 |
| knee_flexion_score | 可选 | 膝屈曲 1–5 |
| trunk_lean_score | 可选 | 躯干前倾 1–5 |
| arm_extension_score | 可选 | 手臂伸展 1–5 |
| landing_buffer_score | 可选 | 落地缓冲 1–5 |
| notes | 可选 | 备注 |

示例：

```csv
video,student,action,cam_view,coach_id,reps,overall_score,standard_flag,prep_score,contact_score,follow_score,knee_flexion_score,trunk_lean_score,arm_extension_score,landing_buffer_score,notes
dig_S01_side_01.mp4,S01,dig,side,coachA,3,8,1,4,4,4,3,4,4,4,准备稍慢
dig_S01_side_01.mp4,S01,dig,side,coachB,3,7,1,4,4,3,3,4,4,4,手臂可以更稳
dig_S02_side_01.mp4,S02,dig,side,coachA,2,5,0,3,2,3,2,3,3,2,击球点偏后
```

## 四、怎么把数据交给我

1. 把视频放进一个目录，例如 `D:\排球验证视频`；
2. 把评分表 CSV 放在一起（或单独路径）；
3. 告诉我两件事：**视频目录路径** + **CSV 路径**，以及主要动作类型；
4. 我会运行：

```bat
cd /d C:\Projects1\排球训练智能分析系统_主项目
python tools\validate_metrics.py --videos "D:\排球验证视频" --ratings "D:\排球验证视频\ratings.csv" --action dig
```

5. 输出：
   - `validation/validation_report.md`：Pearson / Spearman / ICC(2,1) / Bland-Altman + 各生物力学指标与教练评分的相关性；
   - `validation/validation_metrics.csv`：每个视频的系统分与全部指标。

如果有多名教练，**同一个视频写多行**（用 coach_id 区分），工具会自动取平均并计算教练之间的评分一致性（ICC）。

## 五、常见错误（会直接导致实验无效）

1. 同一个统计里混用不同机位（侧面和后视混在一起）→ 分开统计；
2. 用慢放或剪辑后的视频 → 角速度、时序全部失真；
3. 只拍标准动作 → 相关系数会虚高，必须在样本里包含不标准动作；
4. 没有标定就跨距离比较 → 透视误差混入指标；
5. 教练看过系统分数再评分 → 破坏独立性；
6. 每个动作样本太少（<10 段）→ 统计结论不可靠。
