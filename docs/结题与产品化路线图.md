## 三、创新点提炼（答辩可直接用）

1. **面向教学的实时动作分析闭环**：从摄像头采集、实时评分、动作计数，到自动录制、训练记录与报表，形成完整教学闭环，而不是单点算法演示。
2. **多人同框下的主目标分析与身份跟踪**：IoU 跟踪为每名运动员分配稳定 ID，并按“连续性 → 离球距离 → 画面占比”选择主分析对象，支持多人训练场景。
3. **双视角几何校正与结果融合**：用场地四角单应估计局部尺度，对透视引起的角度偏差做补偿；两路视频按动作序号融合分数与反馈，降低单视角遮挡误差。
4. **教学参数可配置与模型可重训**：教练可在网页调整标准阈值，也可在系统内管理数据集、启动 YOLO 训练并一键启用新权重，形成“数据—训练—上线”的闭环。

## 五、四周冲刺计划

### 第 1 周：数据与指标
- 拍 20–30 段校园训练视频（垫球/发球/传球）；
- 请教练给出“标准/不标准”或 1–10 分，建立评分一致性表格；
- 统计系统评分与教练评分的相关系数（Pearson/Spearman）。

### 第 2 周：算法与参数
- 根据一致性结果调整标准动作参数权重；
- 完成双视角标定与两路视频融合实验，记录分数差异；
- 做实时性能测试：分辨率 / 抽帧间隔 / FPS / 延迟曲线。

### 第 3 周：系统与文档
- 用实际数据回归测试全部功能；
- 编写系统说明书、用户手册、测试报告；
- 整理数据集与模型说明，必要时重训一次模型并启用。

### 第 4 周：演示与答辩
- 录制演示视频；
- 制作 PPT，按“痛点 → 方案 → 架构 → 算法 → 实测 → 创新 → 落地”组织；
- 现场彩排：登录 → 标准库 → 视频分析 → 实时分析 → 报表 → 数据集训练。

## 六、8 分钟演示脚本

1. 项目背景与痛点（1 分钟）：教练难以同时关注多人，学生缺少即时反馈；
2. 系统总览（1 分钟）：学生端 / 教练端 / 实时分析 / 数据集训练；
3. 标准动作库（1 分钟）：教练上传示范视频、调整参数、标记关键帧；
4. 视频分析（2 分钟）：上传训练视频 → 评分视频、平均分、最高分、动作数、评分曲线；
5. 实时分析（2 分钟）：摄像头现场演示 → 实时评分、人数与主 ID、实时建议 → 停止自动保存；
6. 数据与报表（1 分钟）：训练记录、规范率、常见问题、双视角融合记录；
7. 总结与创新点（30 秒）：三条创新点 + 落地价值。

## 九、风险与边界

- 数据集不足：需实际拍摄与标注，不能虚构数据；
- 双视角为结果级融合，不是完整三维重建；
- 虚拟摄像头（Iriun）存在独占与黑帧风险，建议用手机浏览器直连；
- 系统为 HTTP→HTTPS 本地部署，不建议暴露公网；
- CPU 训练较慢，建议使用 NVIDIA GPU。
