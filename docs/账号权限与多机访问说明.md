## 五、多台电脑同时使用（局域网）

### 1. 服务器端（运行 AI 的那台电脑）

1. 双击 `启动系统_局域网.bat`，以 **管理员身份运行**（右键 → 以管理员身份运行）；
2. 第一次运行若弹出 Windows 防火墙提示，勾选“专用网络”，点击“允许访问”；
3. 查看本机局域网 IP：

```bat
ipconfig
```

例如本机当前 IP：`10.21.64.13`（DHCP，重启后可能变化）。

### 2. 如果防火墙没有自动放行

用管理员权限打开 PowerShell，执行：

```powershell
New-NetFirewallRule -DisplayName "排球训练智能分析系统 8000" -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8000 -Profile Private
```

### 3. 客户端（其他电脑 / 平板）

浏览器访问：

```
http://10.21.64.13:8000
```

登录自己的账号，即可看到该账号在任意设备上产生的训练记录和视频（数据都存在服务器电脑上）。

### 4. 数据流向

```text
客户端浏览器（摄像头/上传）
        ↓ 画面 / 文件
服务器电脑（AI 推理 + SQLite + 视频存储）
        ↓ 结果
客户端浏览器（显示评分与录像）
```

- 数据只存在服务器电脑；
- 客户端只是采集和显示终端；
- 同一账号只能一台设备在线。

## 七、维护模式（多机使用时保护数据）

- 教练登录后，右上角可点击“进入维护模式/退出维护模式”；
- 维护模式期间，其他设备的分析、上传、实时分析、写入请求都会返回 503；
- 健康检查、登录、修改密码和维护开关仍可用；
- 修改代码或调整数据库前，先进入维护模式并执行 `备份数据库.bat`；
- 修改数据库表结构或安装依赖时，改用 `停止系统.bat` 完全停机更安全。

## 八、HTTPS 与摄像头权限（重要）

浏览器只把 `http://127.0.0.1`、`http://localhost` 视为安全来源。用 `http://局域网IP:8000` 打开时，
Chrome/Edge 会判定“不安全”，从而禁用摄像头。解决方案：使用 HTTPS。

### 1. 生成证书

双击 `生成HTTPS证书.bat`，会在 `certs\` 生成：

- `ca.crt`：本地 CA 证书（用于客户端信任）
- `server.crt` / `server.key`：服务器证书（含本机局域网 IP）

注：如果服务器 IP 变化（DHCP），重新运行一次 `生成HTTPS证书.bat`。

### 2. 以 HTTPS 启动

双击 `启动系统_HTTPS.bat`（监听 `0.0.0.0:8000`）。访问地址：

- 服务器本机：`https://127.0.0.1:8000`
- 局域网其他设备：`https://10.21.64.13:8000`（以实际 IP 为准）

### 3. 客户端信任证书（一次即可）

方式一（免警告，推荐）：

- Windows：双击 `certs\ca.crt` → 安装证书 → 本地计算机 → 受信任的根证书颁发机构 → 完成；
- iPhone/iPad：把 `ca.crt` 传到设备并安装描述文件，再到“设置 → 通用 → 关于本机 → 证书信任设置”开启完全信任。

方式二（快速验证）：浏览器提示“您的连接不是私密连接”时，点“高级 → 继续前往”。
此时是 HTTPS 安全来源，摄像头权限可以正常申请。

### 4. 摄像头排查

- 必须使用 Chrome 或 Edge，不要用内置浏览器；
- Iriun Webcam 客户端要保持运行，手机用数据线连接并信任电脑；
- 实时分析页新增了“摄像头设备 / 刷新设备 / 测试摄像头”，先测试预览再开始分析；
- 若提示占用，关闭微信、腾讯会议、OBS、Windows 相机等程序。
