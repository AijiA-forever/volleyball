## 一、总体思路：从“算法演示”到“教学产品”

### 1. 真实痛点

高校排球教学长期依赖教练人工观察：

- 一名教练难以同时关注多名学生的动作细节；
- 学生课后自主练习缺少专业反馈，错误动作容易固化；
- 传统视频回放只能“看”，不能量化“差在哪里”；
- 专业运动分析系统（多相机、光学动捕）成本高，普通课堂用不起。

### 2. 设计目标

用**单目/双视角普通摄像头 + 轻量模型 + 离线本地服务**，实现：

- 看得见：实时骨架、角度、评分叠加；
- 说得清：把量化偏差转成中文教学建议；
- 留得下：训练记录、报表、进步趋势；
- 用得起：普通笔记本可运行、局域网可用、数据本地保存；
- 可迭代：标准参数可调、数据集可管理、模型可重训。

### 3. 设计原则

- 算法与业务分层：模型只负责“看见”，业务负责“评价与教学”；
- 规则先行、数据驱动：先用可解释规则给出评分，再用教练评分数据校准；
- 实时优先：低延迟、可丢帧、不积压；
- 产品闭环：分析→反馈→记录→报表→训练建议→模型迭代。

```text

   ↓

   ↓
标注视频（WebM）+ SQLite 记录 + 报表 / 趋势
```

## 三、算法原理与理论依据

### 1. 目标检测

| 理论/方法 | 出处 | 核心思想 | 本系统用法 |
| ---- | ---- | ---- | ---- |
| R-CNN | Ross Girshick 等，CVPR 2014，UC Berkeley | 候选区域 + CNN 分类 | 检测范式来源 |
| Faster R-CNN | Shaoqing Ren 等，NIPS 2015，Microsoft Research | RPN 端到端候选框 | 两阶段检测代表 |
| YOLO | Joseph Redmon 等，CVPR 2016，University of Washington | 单阶段回归，实时检测 | 选用单阶段路线 |
| YOLOv8 | Ultralytics（Glenn Jocher 等），2023，开源 | Anchor-free、多任务统一 | 排球检测与姿态模型底座 |

### 2. 人体姿态估计

| 理论/方法 | 出处 | 核心思想 | 本系统用法 |
| ---- | ---- | ---- | ---- |
| COCO 关键点体系 | Tsung-Yi Lin 等，ECCV 2014，Microsoft Research | 定义 17 个人体关键点与 OKS 评价 | 关键点标准 |
| OpenPose | Zhe Cao 等，CVPR 2017，Carnegie Mellon University | Part Affinity Fields 自底向上多人姿态 | 多人姿态思想来源 |
| HRNet | Ke Sun 等，CVPR 2019，Microsoft Research Asia | 保持高分辨率表征 | 高精度姿态代表 |
| YOLO-Pose | Debapriya Maji 等，CVPR Workshops 2022，Texas Instruments | 在 YOLO 上做多人姿态，OKS 损失 | 实时姿态路线 |
| 姿态估计综述 | Ce Zheng 等，arXiv 2020 / ACM Computing Surveys | 系统梳理自顶向下/自底向上方法 | 选型依据 |

本系统取 COCO 17 点中的 12 个核心关节（肩、肘、腕、髋、膝、踝左右各一），用于排球动作描述。

### 3. 多人跟踪

| 理论/方法 | 出处 | 核心思想 | 本系统用法 |
| ---- | ---- | ---- | ---- |
| SORT | Alex Bewley 等，ICIP 2016，University of Sydney | 卡尔曼滤波 + 匈牙利匹配 | 跟踪框架来源 |
| DeepSORT | Nicolai Wojke 等，ICIP 2017 | 加入外观 ReID | 后续升级方向 |
| ByteTrack | Yifu Zhang 等，ECCV 2022，华中科技大学 / 字节跳动 | 关联所有检测框，低分框二次匹配 | 后续升级方向 |
| IoU 匹配 | Jaccard 相似度，检测评价通用 | 框重叠度 | 当前轻量跟踪实现 |

本系统采用 IoU 贪心匹配的轻量跟踪：为每名运动员分配稳定 ID；主分析对象按“上一帧主 ID → 离球最近 → 画面占比最大”选择，解决“多人同框只分析一人”的问题。

### 4. 几何校正

| 理论/方法 | 出处 | 核心思想 | 本系统用法 |
| ---- | ---- | ---- | ---- |
| 直接线性变换（DLT） | Y. I. Abdel-Aziz, H. M. Karara，1971，ISP Symposium | 由点对应求解投影矩阵 | 单应矩阵求解基础 |
| 多视图几何 | Richard Hartley, Andrew Zisserman，《Multiple View Geometry in Computer Vision》，Cambridge University Press，2000/2004 | 单应、极几何、三角测量 | 几何校正理论依据 |
| 相机标定 | Zhengyou Zhang，IEEE TPAMI 2000，Microsoft Research | 平面棋盘格标定内参 | 后续完整标定方向 |

本系统用场地四角点求单应矩阵 H，估计不同位置的局部像素尺度（米/像素），对关键点垂直方向做比例补偿，降低“近大远小”对关节角度的影响；双视角则按动作序号融合两路分数与反馈。

### 5. 运动学特征与评分

- 关节夹角：欧几里得几何中的余弦定理（古典几何，Euclid《几何原本》约公元前 300 年）：

```text
cos θ = (BA · BC) / (|BA| × |BC|)
```

- 特征：关节角度、腕-肩高度比、髋-肩比例、球-手臂距离；
- 评分：多特征加权，落在标准区间得满分，偏离则线性衰减；80 分以上判为标准；
- 理论来源：规则型专家系统思想。早期代表 MYCIN（Edward Shortliffe，斯坦福大学，1970 年代）证明“规则 + 知识库”可做专业判断；本系统把教练经验写成可调参数。

### 6. 动作区间检测

- 双阈值滞回思想：Schmitt trigger（Otto Schmitt，1938）提出滞回比较；Canny 边缘检测（John Canny，IEEE TPAMI 1986，MIT）使用双阈值抑制噪声；
- 本系统：进入阈值（球-手距离 < 1.3×身高）宽松进入，折返/最小 4 帧严格结算，避免阈值抖动导致重复计数；
- 排球轨迹插值：匀速运动模型预测丢失帧位置，最多容忍 5 帧，提升实时连续性。

### 7. 教学反馈理论

| 理论 | 出处 | 结论 | 本系统用法 |
| ---- | ---- | ---- | ---- |
| 形成性评价 | Paul Black, Dylan Wiliam，1998，Assessment in Education（King's College London） | 及时、具体的反馈显著提升学习效果 | 实时评分 + 中文建议 |
| 反馈的力量 | John Hattie, Helen Timperley，2007，Review of Educational Research（University of Auckland） | 反馈要指向目标与改进路径 | 反馈直接指出“膝角不足”等 |
| 运动技能学习理论 | Richard A. Schmidt，1975，Psychological Review | 结果知识（KR）影响技能习得 | 用分数与偏差量化结果 |
| 反馈频率假设 | Salmoni, Schmidt & Walter，1984，Psychological Bulletin | 反馈过频可能产生依赖 | 未来做自适应反馈频率 |

## 四、系统如何实现

### 1. 架构分层

```text
表现层  index.html + auth/extra/dataset_features.js
接口层  main.py（FastAPI：REST + WebSocket + 静态资源）
业务层  analysis_service.py（分析编排、实时会话、融合）
算法层  analyzer.py / body.py / pose_judge.py / tracking.py / geometry.py / volleyball_detect.py
数据层  storage.py（SQLite：账号、标准库、记录、标定、数据集、训练任务）
```

### 2. 关键实现点

- 模型只加载一次：`AnalysisService` 单例 + 锁串行，避免 CPU 争用；
- 分析输出统一为 WebM（VP8/VP9），解决浏览器不兼容 MP4 的问题；
- 实时链路：浏览器抽帧 → WebSocket → 后端推理 → 标注帧回传 → 实时指标；
- 记录结构：一次训练 `training_sessions` + 多次动作 `session_attempts`，支撑报表；
- 标准参数数据化：教练在网页改阈值，评分立即变化；
- 账号与权限：PBKDF2 哈希、单点登录令牌、学生数据隔离；
- 运维：维护模式文件锁、数据库备份、HTTPS 启动脚本。

### 3. 数据库表

| 表 | 作用 |
| ---- | ---- |
| users | 账号、角色、密码哈希、登录令牌 |
| standards | 标准动作、参数、示范视频 |
| training_sessions | 一次训练（视频/实时/双视角） |
| session_attempts | 一次动作的分数与反馈 |
| calibrations | 视角标定 |
| datasets / dataset_items | 数据集管理与样本 |
| training_jobs | 模型训练任务与日志 |

## 五、创新点论述（可辩护版）

> 说明：以下为“组合创新 / 应用创新 / 工程创新”，不声称提出全新算法；这是本科创新项目最稳妥、也最容易被评审接受的定位。

### 创新点 1：面向教学场景的“多人跟踪 + 主目标分析 + 实时评分闭环”

- 前人工作：Ibrahim 等（CVPR 2016，Simon Fraser University）构建排球比赛数据集并做群体活动识别，目标是比赛语义标签；OpenPose（CVPR 2017）、HRNet（CVPR 2019）解决姿态精度；SORT/DeepSORT/ByteTrack 解决通用跟踪。
- 未完成之处：上述工作很少把“个体 ID + 教学标准 + 逐动作评分 + 中文反馈 + 训练记录”串成课堂可用的实时闭环。
- 我们的做法：IoU 跟踪分配 ID，主目标按连续性与球距离选择；标准库可配置；实时评分并自动落库。
- 落地价值：一名教练可同时观察多人，学生每练一次都有记录与建议。
- 验证方式：多人同框 ID 稳定性、主目标切换正确率、授课教师可用性反馈。

### 创新点 2：场地单应驱动的透视尺度补偿 + 双视角结果融合

- 前人工作：多视图几何（Hartley & Zisserman，2000/2004）、Zhang 标定（TPAMI 2000）用于三维重建与相机标定；多视角三维姿态精度高但部署重。
- 未完成之处：普通教室只有 1–2 台普通摄像头，难以做完整三维重建；单目透视会让远处学生的关节角度失真。
- 我们的做法：用场地四角求单应，估计局部尺度并对垂直方向做补偿；两路视频按动作序号融合分数与反馈。
- 落地价值：不增加昂贵设备即可降低视角误差，支持双机位课堂。
- 验证方式：同一动作近/远位置角度差异对比、单/双视角评分一致性对比。

### 创新点 3：教学闭环 + 可配置标准 + 数据集重训的一体化离线系统

- 前人工作：开源排球分析项目（如 `volleyball_analytics`）主要面向比赛转播；体育教学系统多为单机演示或单一功能。
- 未完成之处：缺少“标准库—评分—记录—报表—重训—权限—运维”的完整产品化闭环。
- 我们的做法：学生/教练双角色、标准参数在线调整、训练记录与报表、数据集管理与 YOLO 重训、一键启用新权重、维护模式与备份。
- 落地价值：一个可交付、可维护、可迭代的教学软件，而不是一次性演示脚本。
- 验证方式：功能覆盖表、接口测试、教师试用反馈、重训前后指标对比。

### 创新点 4：可解释的规则化反馈 + 可调参数（教学可解释性）

- 前人工作：深度模型端到端打分可解释性差；教练难以干预模型内部。
- 我们的做法：评分由关节角度阈值与权重组成，教练可直接修改参数；反馈由规则生成，学生能理解。
- 理论支撑：规则型专家系统（MYCIN，Shortliffe，1970s）+ 形成性评价（Black & Wiliam，1998）。
- 验证方式：评分与教练评分一致性（Pearson/Spearman）、反馈可理解度问卷。

## 七、结题/论文可做的量化实验

1. 评分一致性：系统分 vs 教练分（Pearson / Spearman / ICC），20–30 段视频；
2. 关键点稳定性：不同光照/距离下关键点检出率与角度波动；
3. 透视校正效果：同一动作近远位置校正前后角度差；
4. 双视角融合：单视角 vs 双视角评分与教练评分的一致性提升；
5. 实时性能：分辨率/抽帧间隔 vs FPS 与端到端延迟曲线；
6. 多人跟踪：ID 保持率、主目标切换正确率；
7. 教学效果：使用系统前后学生动作规范率对比（准实验设计）；
8. 可用性：教师/学生 SUS 量表与访谈。

## 八、答辩叙事线（可直接照着讲）

1. 痛点：教练精力有限，学生缺少即时、可理解的反馈；
2. 方案：普通摄像头 + 轻量姿态模型 + 教学标准库 + 实时/离线双模式；
3. 原理：检测→跟踪→姿态→几何校正→运动学特征→规则评分→反馈；
4. 系统：学生端、教练端、实时分析、数据集训练、权限与运维；
5. 验证：图片/视频/实时/权限/训练链路测试 + 一致性实验；
6. 创新：多人主目标实时闭环、单应+双视角融合、教学可配置重训闭环、可解释反馈；
7. 落地：离线部署、局域网多机、维护备份、HTTPS 摄像头；
8. 展望：时序动作建模（ST-GCN/DTW）、三维重建、移动端、教学效果实验。
