# 排球训练智能分析系统（Web 整合版）
## 项目文件清单 + 陌生电脑运行指南

> 项目位置：`C:\Projects1\volleyball_system_v2`
> 系统形态：FastAPI 本地服务 + 浏览器网页端（学生端 / 教练端）
> 适用系统：Windows 10 / 11 64 位

---

## 一、系统能做什么

- 上传训练视频 / 图片，自动检测人体关键点与排球，判断垫球、发球、传球、扣球动作是否规范；
- 输出评分视频（WebM）、平均分、最高分、动作数、标准数、逐动作反馈和评分曲线；
- 学生端：练习分析、标准动作视频学习（慢放 / 关键帧）、训练历史记录；
- 教练端：标准动作库管理、训练报表、常见问题统计、场地视角标定；
- 数据保存在本地 SQLite 数据库，离线可用。

## 三、陌生电脑部署步骤

### 0. 硬件建议

- Windows 10 / 11 64 位；
- 内存 8 GB 起，推荐 16 GB；
- 硬盘预留 5 GB 以上（视频结果会持续增长）；
- 有 NVIDIA 显卡可选装 CUDA 版 PyTorch，CPU 也能运行但速度较慢。

### 1. 安装 Miniconda

到 <https://docs.conda.io/en/latest/miniconda.html> 下载 Windows 64 位安装包并安装。
安装时勾选 Add to PATH（如未勾选，后面用“开始菜单 → Anaconda Prompt”操作）。

### 2. 复制项目

把项目文件夹复制到新电脑，例如：

```
D:\排球训练智能分析系统
```

注意必须包含 `pose_best.pt` 和 `best.pt` 两个模型文件。

### 3. 创建 Python 环境

打开 “Anaconda Prompt”，执行：

```bat
conda create -n volleyball python=3.11 -y
conda activate volleyball
```

### 4. 安装依赖

CPU 电脑：

```bat
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
```

有 NVIDIA 显卡：先到 <https://pytorch.org/get-started/locally/> 选择对应 CUDA 版本安装 PyTorch，再执行：

```bat
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
```

### 5. 验证依赖

```bat
python -c "import cv2, torch, ultralytics, fastapi; print('dependencies ok')"
```

### 6. 启动系统

进入项目目录后执行：

```bat
cd /d D:\排球训练智能分析系统
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

或者直接双击 `启动系统.bat`。

看到下面输出即启动成功：

```
Uvicorn running on http://127.0.0.1:8000
Application startup complete.
```

### 7. 打开网页

浏览器（推荐 Chrome / Edge）访问：

```
http://127.0.0.1:8000
```

第一次打开请按 `Ctrl+F5` 强制刷新，避免旧缓存。

## 四、用系统分析训练视频的操作步骤

1. 打开 <http://127.0.0.1:8000>；
2. 点击右上角“进入/登录”，选择身份：
   - 学生：填写姓名后进入；
   - 教练：可管理标准动作库、报表、标定；
3. 进入“练习分析”，选择动作类型（垫球 / 发球 / 传球 / 扣球）；
4. 如教练已建立标准动作，可在“对照标准”中选择，否则用系统默认参数；
5. 选择“视频分析”页签，点击上传框选择训练视频（mp4 / avi / mov）；
6. 点击“开始分析”；
7. 等待处理完成（看不到百分比进度，属正常；CPU 处理 6–10 秒视频约需 0.5–2 分钟，GPU 更快）；
8. 结果区会显示：
   - 可播放的评分视频（WebM）；
   - 平均分、最高分、动作数、标准数、总帧数；
   - 每个动作的得分、是否标准、文字反馈；
   - 评分曲线图；
9. 分析结果自动保存到数据库，可在“我的训练记录”里再次查看。

### 摄像头实时分析（完整实时模块）

1. 在“练习分析”切换到“摄像头实时”；
2. 点击“开始实时分析”，允许浏览器访问摄像头；
3. 画面实时回传并叠加关键点、角度、评分与建议；
4. 面板实时刷新当前得分、动作数、标准数、平均分、最高分；
5. 点击“停止并保存”，系统自动生成实时训练录像（WebM）并写入训练记录；
6. 可在“我的训练记录”中回看录像、分数与反馈。

实时分析的原理与理论来源见《实时分析功能说明与理论来源.md》。

## 五、教练端操作步骤

### 1. 标准动作库

1. 以教练身份登录；
2. 进入“标准动作库管理”；
3. 点击“新建标准动作”，填写名称、动作类型、说明；
4. 上传教练示范视频（可选上传封面）；
5. 在参数 JSON 中调整标准阈值（角度区间、权重），例如：

```json
{
  "left_elbow": [160, 180],
  "right_elbow": [160, 180],
  "left_knee": [100, 150],
  "right_knee": [100, 150],
  "hip_height_ratio": [0.3, 0.7],
  "weights": {"elbow": 0.4, "knee": 0.4, "hip": 0.2},
  "keyframes": [{"time": 1.2, "label": "准备姿势"}]
}
```

6. 打开示范视频，拖动到动作关键阶段，点击“在当前时间添加关键帧”；
7. 保存后学生即可在“标准动作学习”中慢放观看。

### 2. 训练报表

进入“训练报表”，可查看：
- 学生数量、训练次数、动作总数、规范率、平均分；
- 常见问题排行；
- 单个学生的训练明细。

### 3. 视角标定

进入“视角标定”，上传一张含场地的画面，依次点击四个端点（远左、远右、近左、近右），保存到数据库。

## 七、常见问题排查

### 1. 网页显示“拒绝建立连接”

服务没启动。重新执行：

```bat
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

### 2. 页面点击没反应

按 `Ctrl+F5` 强制刷新；若仍无响应，按 F12 打开浏览器控制台看是否有红色报错。

### 3. 评分视频无法播放

确认访问的是 `.webm` 结果；如果历史记录仍指向旧的 `.mp4`，重新分析一次即可生成 `.webm`。

### 4. 分析结果没有分数 / 动作数

说明视频中未检测到连续有效姿态或排球轨迹。建议：
- 画面中人物完整、光照充足；
- 排球清晰可见，避免严重遮挡；
- 使用 6–15 秒的短片段重新分析。

### 5. 处理速度慢

- 使用 NVIDIA 显卡 + CUDA 版 PyTorch；
- 缩短视频长度；
- 系统已把输出视频限制到 960 宽以加快编码。

### 6. 端口被占用

```bat
netstat -ano | findstr :8000
taskkill /PID <进程ID> /F
```

或换端口启动：

```bat
python -m uvicorn main:app --host 127.0.0.1 --port 8001
```

### 7. 依赖安装失败

使用国内镜像：

```bat
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
```

### 8. 模型文件缺失

确保项目根目录存在 `pose_best.pt` 和 `best.pt`，否则姿态或排球检测无法工作。

## 八、可选：用自己的数据重新训练模型

如果需要让模型更适配你们的校园训练场景：

### 1. 姿态模型（12 个核心关键点）

1. 用标注工具标注人体关键点，导出 YOLO pose 格式；
2. 编写 `data.yaml`，指定训练集 / 验证集路径和关键点数量；
3. 训练命令示例：

```bat
yolo pose train model=yolov8n-pose.pt data=data.yaml epochs=100 imgsz=640
```

4. 训练完成后，把 `runs\pose\train\weights\best.pt` 改名覆盖项目根目录的 `pose_best.pt`。

### 2. 排球检测模型

```bat
yolo detect train model=yolov8n.pt data=volleyball.yaml epochs=100 imgsz=640
```

训练完成后把 `best.pt` 覆盖项目根目录的 `best.pt`。

> 重新训练后建议先用 `onepeople.mp4` 或自己的短视频重新验证一次，再用于正式训练。
