# 实时分析功能说明与理论来源

> 模块位置：系统首页 → 练习分析 → “摄像头实时”页签
> 对应代码：`main.py`（WebSocket 接口）、`analysis_service.py`（实时会话引擎）、`analyzer.py`（动作区间状态机）、`pose_judge.py`（评分与反馈）、`index.html`（实时界面）

---

## 一、系统现在有没有实时分析

有。当前版本已经把原来“只返回单帧评分”的摄像头预览升级为完整实时分析模块，具备以下能力：

- 浏览器摄像头逐帧采集，低延迟传输到本机后端；
- 实时人体关键点检测、排球检测、动作规范评分；
- 实时显示当前得分、动作数、标准数、平均分、最高分；
- 实时显示中文指导建议（例如“肘关节弯曲过大，需伸直”“膝盖适当弯曲，降低重心”）；
- 实时动作区间结算：达到连续有效帧即计一次动作；
- 停止后自动录制整段分析视频（WebM）并写入“我的训练记录”，可在训练报表中统计。

## 二、如何使用实时分析

1. 启动系统：双击 `启动系统.bat`，或在项目目录运行：

```bat
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

2. 浏览器打开 `http://127.0.0.1:8000`，强制刷新一次（Ctrl+F5）。
3. 右上角登录，选择“学生”身份并填写姓名。
4. 进入“练习分析”，选择动作类型（垫球 / 发球 / 传球 / 扣球），如需对照标准动作可在“对照标准”中选择。
5. 切换到“摄像头实时”页签。
6. 点击“开始实时分析”，允许浏览器访问摄像头。
7. 画面上会实时显示关键点、骨架、角度和评分；面板上会同步刷新：
   - 当前得分；
   - 动作数、标准数；
   - 平均分、最高分；
   - 当前指导建议。
8. 训练结束后点击“停止并保存”。
9. 系统会自动生成实时训练录像和训练记录，并显示训练编号；可到“我的训练记录”查看录像、分数和反馈。

> 实时分析建议在光线充足、人物全身入镜、背景简洁的教室或球场使用；建议使用 640×480 及以上摄像头。

## 三、实时分析的完整数据流

```text
浏览器摄像头
   ↓ getUserMedia（640×480）
Canvas 抽帧（约 8–9 FPS，自适应丢帧）
   ↓ WebSocket /ws/camera（Base64 JPEG）
FastAPI 后端
   ↓
AnalysisService.start_realtime()      建立实时会话
   ↓
handle_realtime_frame()
   ├─ YOLO-Pose 关键点检测
   ├─ 排球检测 + 轨迹插值
   ├─ judge_pose() 关节角度评分
   ├─ ActionSession.update() 动作区间状态机
   └─ WebM 录像写入（960 宽）
   ↓
WebSocket 返回：标注帧 + 实时统计 + 中文反馈
   ↓
停止时 stop_realtime()
   ├─ 释放录像文件
   ├─ 汇总平均分 / 最高分 / 动作数 / 评分曲线
   └─ 写入 SQLite training_sessions / session_attempts
```

## 四、理论来源

### 1. 二维人体姿态估计

- 理论基础：深度学习人体关键点检测。当前使用 YOLO-Pose 系列模型（基于 COCO 17 关键点体系），通过回归/热力图方式定位人体关节；
- 本项目取其中 12 个核心关节点（肩、肘、腕、髋、膝、踝左右各一对）用于排球动作分析；
- 理论要点：卷积极端特征提取 + 关键点坐标回归，推理速度可达实时，适合普通笔记本 CPU 运行。

### 2. 运动学特征：关节夹角

- 理论基础：余弦定理。对三个关节 (A, B, C)，以 B 为顶点：

```text
cos θ = (BA · BC) / (|BA| × |BC|)
θ = arccos(cos θ)
```

- 举例：肩–肘–腕夹角反映手臂伸展程度；髋–膝–踝夹角反映屈膝程度；
- 这是计划书中“膝关节 110°–130°、击球点距腕关节约 10 cm”等标准参数的算法基础。

### 3. 动作区间检测：状态机 + 滞回阈值

- 理论基础：时序事件检测中的“双阈值滞回”思想，避免阈值附近抖动导致重复计数；
- 进入阈值：球与手臂距离小于 1.3 倍身高（宽松进入）；
- 折返判定：球轨迹出现 V 形（最低点位于区间中部），或动作区间达到最小有效帧数（4 帧）；
- 作用：把连续视频切分为一次次独立动作，为计数、评分和反馈提供时间边界。

### 4. 排球轨迹插值

- 理论基础：匀速直线运动模型。根据最近两帧球心位置估计速度，在检测丢失时预测下一帧位置（动量保留），最多容忍 5 帧丢失；
- 作用：提高实时画面中排球检测的连续性和稳定性。

### 5. 动作规范评分模型

- 理论基础：多特征加权评分。对各关节角度/高度比例分别给出 0–100 分，再按动作权重加权：

```text
总分 = Σ(特征得分 × 权重)
```

- 垫球：肘部伸展 40% + 膝盖弯曲 40% + 身体前倾 20%；
- 发球：发球臂 50% + 手腕高度 30% + 腿部 20%；
- 传球：肘部 60% + 手腕高度 40%；
- 扣球：击球臂 50% + 膝盖 40% + 身体伸展 10%；
- 80 分以上判定为标准动作。

### 6. 自然语言反馈

- 理论基础：规则引擎。将量化偏差映射为教学语言，例如：
  - 肘部得分 < 80 → “保持双臂伸直，肘部不要弯曲”；
  - 膝盖得分 < 80 → “膝盖适当弯曲，降低重心”；
  - 手腕高度不足 → “双手举过头顶，手腕高于肩膀”。
- 对非专业学生更友好，符合“辅助教学”的项目定位。

### 7. 实时传输：WebSocket

- 理论基础：全双工长连接。相比 HTTP 轮询，WebSocket 建立一次连接后可双向持续传输帧数据与结果，延迟更低；
- 前端采用“发送—等待响应—再发送”的背压策略，后端慢时自动丢帧，保证画面与评分不积压、不延迟累积。

### 8. 时序鲁棒性

- 关键点置信度过滤（< 0.3 丢弃）；
- 丢失时沿用最近一次有效关键点；
- 排球轨迹预测与插值；
- 评分使用区间平均，而不是单帧分数。

## 五、工程实现要点（算法到产品）

| 算法能力 | 产品化实现 |
| ---- | ---- |
| 关键点检测 | 封装在 `body.py` / `analyzer.py`，统一输出结构化关键点 |
| 动作评分 | `pose_judge.py` 输出分数 + 是否标准 + 反馈文本 |
| 动作计数 | `ActionSession` 状态机，实时累计 |
| 实时传输 | WebSocket 接口 + 前端背压抽帧 |
| 训练留痕 | 自动录 WebM + SQLite 落库 + 报表 |
| 标准库 | 教练可覆盖默认参数，学生选择对照标准 |
| 用户体验 | 实时指标卡、反馈列表、停止后自动保存、历史可回看 |

## 六、实测表现与适用边界

实测（CPU 环境，onepeople.mp4 90 帧模拟实时输入）：

- 单帧推理约 20–30 ms；
- 90 帧识别 4 个动作，2 个标准动作；
- 平均分 85.6，最高分 100；
- 自动生成 13 MB WebM 录像，可正常读取与播放。

适用边界：

- 单人、全身入镜、侧身或正面视角效果最好；
- 多人同时出现在画面时，目前只取姿态置信度最高的关键点，尚未做多人身份跟踪；
- 排球被严重遮挡时依赖轨迹插值，长时间丢失会停止计数；
- 已预留视角标定数据表，后续可扩展到多视角几何校正。
